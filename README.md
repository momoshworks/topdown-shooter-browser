# Top-Down Shooter RPG - Browser Version

لعبة تصويب من الأعلى (Top-Down Shooter) تعمل مباشرة في المتصفح باستخدام HTML5 Canvas و JavaScript puro.

## المميزات

- **الحركة**: WASD / الأسهم للحركة، الماوس للتصويب
- **الإطلاق**: Spacebar أو Click يسار
- **الاندفاع**: Shift / Ctrl للاندفاع السريع مع مناعة مؤقتة
- **نظام الموجات**: أعداء يتزايدون في الصعوبة والموجات
- **3 أنواع من الأعداء**:
  - 🟢 **عادي** (Melee): يلاحق ويهاجم بالتماس
  - 🟠 **قناص** (Ranged): يطلق مقذوفات من مسافة
  - 🟣 **مهاجم** (Charger): بطيء لكن يتحمل ضربات، يهجم بسرعة عالية
- **نظام الخبرة والترقية**: اكسب خبرة → ارتقِ مستوى → اختر من 3 ترقيات عشوائية
- **8 ترقيات متاحة**: ضرر، سرعة إطلاق، صحة، مقذوفات إضافية، سرعة حركة، اختراق، تجديد صحة، دفع أقوى
- **نقاط صحية وقنابل خبرة** تتساقط من الأعداء
- **حفظ أعلى نتيجة** في localStorage
- **دعم اللمس للجوال**: عصا تحكم افتراضية + أزرار إطلاق/اندفاع
- **تأثيرات بصرية**: جسيمات، اهتزاز الشاشة، فلاش الضرر، مسارات المقذوفات
- **واجهة عربية كاملة** مع RTL

## كيفية التشغيل

### الطريقة الأسهل:
1. افتح ملف `index.html` مباشرة في المتصفح (Double-click)
2. أو اسحب الملف إلى نافذة المتصفح

### عبر خادم محلي (موصى به للأداء):
```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx serve .

# ثم افتح http://localhost:8000
```

## ميكانيكا اللعب

### نظام الموجات
- موجة 1: 5 أعداء عاديين
- كل موجة: 30% أعداء أكثر
- موجة 2+: يفتح نوع "قناص"
- موجة 4+: يفتح نوع "مهاجم"
- 3 ثوانٍ راحة بين الموجات

### الترقيات (عند الارتقاء)
تظهر 3 خيارات عشوائية من:
- ⚔️ **ضرر +20%**
- ⚡ **سرعة إطلاق +15%**
- ❤️ **صحة قصوى +25**
- 💫 **مقذوف إضافي**
- 👟 **سرعة حركة +20%**
- 🎯 **اختراق +1**
- 💚 **تجديد صحة +0.5/ثانية**
- 💨 **دفع أقوى +50%**

### الأعداء
| النوع | الصحة | الضرر | السرعة | السلوك | المكافأة |
|-------|-------|-------|--------|---------|----------|
| عادي | 30 | 10 | 120 | ملاحقة | 5 XP |
| قناص | 40 | 12 | 100 | إطلاق نار | 8 XP |
| مهاجم | 80 | 20 | 80/400* | هجوم سريع | 15 XP |

*سرعة المهاجم: 80 عادي، 400 أثناء الهجوم

## التقنيات المستخدمة

- **HTML5 Canvas** - للرسم عالي الأداء
- **Vanilla JavaScript (ES6+)** - لا توجد مكتبات خارجية
- **requestAnimationFrame** - حلقة لعب سلسة 60 FPS
- **localStorage** - حفظ أعلى نتيجة
- **Touch Events** - دعم كامل للشاشات اللمسية
- **CSS3** - واجهات متحركة مع transitions/animations
